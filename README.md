# USB2UART

USB-C to four UART ports, based on the CH344Q and designed in KiCad.

- `usb2uart-kicad/` — KiCad schematic and PCB. Open `usb2uart-kicad.kicad_pro` to get started.
- `manufacturing/` — Gerbers, drill files, BOM, and component placement CSV for JLCPCB.
- `docs/` — Reference documentation.
